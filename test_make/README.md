# FOSSDEV Project: Makefile Automation & Quality Assurance

Этот репозиторий демонстрирует подход к управлению Python-проектом, где **Make** выступает единой точкой входа (Single Source of Truth) для управления окружением, зависимостями и проверками качества кода.

## Цель проекта
Демонстрация принципов "By-design not by-mistake" и "Stateless execution". Вместо ручной активации виртуального окружения (`source venv/bin/activate`), все команды в Makefile явно вызывают исполняемые файлы из `.venv/bin/`, что гарантирует воспроизводимость и изоляцию от системного окружения.

## Быстрый старт

Для выполнения всех действий и проверок достаточно одной команды:
```bash
make all
